Questions fréquentes

Ce que vous voulez savoir
avant de postuler.

Est-ce vraiment gratuit pour les candidats ?

Oui, absolument. Notre rémunération est versée exclusivement par les entreprises qui recrutent, uniquement quand une embauche est conclue. Le candidat ne paie rien à aucune étape.

Quels profils recherchez-vous ?

Tous les métiers de l'IT : développeurs (front, back, mobile), DevOps, Cloud Engineers, Data Engineers, Data Scientists, ingénieurs cybersécurité, admins systèmes & réseaux, ingénieurs infrastructure, testeurs QA. Étudiants en dernière année également acceptés.

Quel niveau de français est requis ?

Un niveau B2 minimum est nécessaire pour travailler en entreprise française. Nous évaluons votre niveau lors de l'entretien visio et pouvons vous orienter si besoin.

Combien de temps prend le processus ?

Retour sous 24h après votre candidature. Si votre profil correspond, l'entretien visio est programmé dans la semaine. Le test technique dure environ 1h. Mise en relation avec les entreprises dans les 5 jours suivants.

Gérez-vous les démarches administratives ?

Nous vous accompagnons dans la coordination avec l'entreprise pour les aspects administratifs (documents nécessaires, suivi du dossier). Nous vous orienterons vers les bons interlocuteurs pour le visa talent et le permis de travail.
